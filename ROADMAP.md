# Roadmap

This roadmap organizes the repository into progressive phases, from foundational AI agent concepts to enterprise-grade use cases.

## Phase 1: Foundations

Objective: Build a clear conceptual foundation for AI agents and agentic workflows.

Planned work:

- Define what an AI agent is
- Compare agents, workflows, chatbots, and automations
- Document core concepts: tools, memory, context, planning, actions, observations, and evaluation
- Create foundational notes for prompt engineering and agent instruction design

## Phase 2: Simple Agents

Objective: Build small runnable examples that demonstrate basic agent behavior.

Planned examples:

- Simple Q&A agent
- Calculator tool agent
- Basic task-planning agent
- Simple command-line assistant

## Phase 3: Tool-Using Agents

Objective: Explore how agents interact with external tools and systems.

Planned examples:

- API tool agent
- File reader agent
- Search-style agent
- Database query agent
- Function-calling examples

## Phase 4: RAG Agents

Objective: Build agents that retrieve information before generating responses.

Planned examples:

- Local document Q&A agent
- Vector store retrieval example
- RAG prompt patterns
- Document chunking notes
- RAG evaluation notes

## Phase 5: AWS Bedrock Agents

Objective: Build hands-on examples using Amazon Bedrock and related AWS services.

Planned examples:

- Bedrock basic model invocation
- Bedrock Knowledge Base example
- Bedrock Agent with action group
- Lambda-backed tool integration
- API Gateway integration concept

## Phase 6: Agent Frameworks

Objective: Compare and experiment with common AI agent frameworks.

Frameworks to explore:

- LangChain
- CrewAI
- LlamaIndex
- AgentCore
- MCP-related examples

Deliverables:

- Framework comparison matrix
- Strengths and weaknesses
- Enterprise fit notes
- Lessons learned

## Phase 7: Multi-Agent Systems

Objective: Explore how specialized agents coordinate to complete larger tasks.

Planned examples:

- Planner / Researcher / Reviewer workflow
- Software delivery agent workflow
- Warranty triage multi-agent pattern
- Multi-agent orchestration notes

## Phase 8: Enterprise Use Cases

Objective: Connect agentic AI patterns to practical enterprise scenarios.

Potential use cases:

- Warranty claim review
- Quality issue triage
- Dealer support assistant
- Project status summarizer
- Incident response assistant
- Requirements analysis assistant

## Phase 9: Evaluation and Governance

Objective: Document how to evaluate, monitor, and govern AI agents responsibly.

Topics:

- Agent evaluation framework
- Hallucination risk
- Human-in-the-loop controls
- Security and permissions
- Cost management
- Observability
- Production readiness criteria

## Phase 10: Portfolio-Grade Capstones

Objective: Create polished examples that demonstrate professional capability.

Potential capstones:

- Warranty claim review agent
- Quality issue triage agent
- RAG-based technical support assistant
- Multi-agent software delivery assistant
- Bedrock-based enterprise assistant prototype
