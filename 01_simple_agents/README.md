# 01 Simple Agents

Purpose: store small runnable examples that demonstrate basic agent behavior.

## Learning Objectives

- Build simple command-line agents
- Practice prompt design and response handling
- Understand the difference between a basic assistant and an agent
- Establish reusable project patterns for future examples

## Suggested Experiments

- Simple Q&A agent
- Calculator tool agent
- Basic task-planning agent
- Simple command-line assistant
