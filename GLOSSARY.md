# Glossary

This glossary defines common terms used throughout the AI agents training repository.

## Agent

An AI-enabled system that can interpret a goal, use context, select tools, perform actions, and produce a response or outcome.

## Agentic AI

AI systems designed to perform multi-step tasks with some level of planning, tool use, context management, and decision-making.

## Tool

An external capability the agent can call, such as an API, database query, calculator, file reader, search function, or cloud service.

## Function Calling

A pattern where a language model selects and invokes a structured function or tool based on the user request and available tool definitions.

## Retrieval-Augmented Generation

A pattern where an AI system retrieves relevant information from a knowledge source before generating a response.

## RAG

Abbreviation for Retrieval-Augmented Generation.

## Vector Store

A database or storage system that stores text, documents, or other objects as embeddings for semantic search.

## Embedding

A numerical representation of text or data that captures semantic meaning and allows similarity comparisons.

## Prompt Engineering

The practice of designing instructions, examples, context, and constraints to guide model behavior.

## System Prompt

The high-level instruction that defines an AI assistant or agent's role, behavior, boundaries, and operating rules.

## Memory

Information retained by an agent to support future steps, conversations, or decisions.

## Context Window

The amount of information a model can consider during a single interaction.

## Planning

The process of decomposing a task into steps or deciding how to reach a goal.

## Action

A concrete operation performed by an agent, often through a tool or external system.

## Observation

Information returned to an agent after it performs an action or calls a tool.

## Multi-Agent System

A system where multiple specialized agents coordinate to complete a larger task.

## Orchestration

The coordination of steps, tools, agents, data flow, and control logic in an AI workflow.

## Human-in-the-Loop

A design pattern where humans review, approve, correct, or intervene in AI-driven decisions or actions.

## Evaluation

The process of assessing an agent's accuracy, reliability, safety, usefulness, and business value.

## Guardrail

A control mechanism used to reduce undesired behavior, unsafe actions, hallucinations, or policy violations.

## Hallucination

An incorrect or unsupported output generated by an AI model that may appear plausible.

## Enterprise AI

AI systems designed for organizational use, typically requiring governance, security, reliability, integration, monitoring, and measurable business value.
