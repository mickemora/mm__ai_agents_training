# 02 Tool-Using Agents

Purpose: explore agents that interact with external tools and systems.

## Learning Objectives

- Understand how agents select and use tools
- Practice function calling patterns
- Connect agents to APIs, files, databases, or local utilities
- Learn how tool outputs become observations for the agent

## Suggested Experiments

- API tool agent
- File reader agent
- Search-style agent
- Database query agent
- Function-calling examples

## Future Content

Examples should document the tool contract, input schema, output schema, error handling, and security considerations.
